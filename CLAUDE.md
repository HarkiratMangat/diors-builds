### Database schema gotcha
Mongoose only persists fields **declared in the schema**. Several past bugs were exactly this: code setting `doc.newField = x; await doc.save()` where `newField` was never added to the Mongoose schema — it worked in-memory but silently reverted on the next fresh fetch. **Whenever you add a new field anywhere, add it to the corresponding schema in `models/` in the same change.** Full data-model detail: `.claude/rules/models.md`.
